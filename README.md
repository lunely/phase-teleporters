# Phase Teleporters

<a href="https://boosty.to/lunelydev"><img src="https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/boosty/default.svg" alt="Boosty" width="32"></a>

**Phase Teleporters** — a lightweight tech mod for Minecraft designed for teleportation

Phase Teleporters lets you travel conveniently both within the same dimension and between different dimensions

The goal is to provide a convenient system for teleportation and resource transfer without requiring a huge tech mod just for these features

## Features

- **Local Teleporter** — travel between linked locations within the same dimension
- **Interdimensional Teleporter** — teleport between different dimensions
- **Portable Teleporter** — travel to configured locations without having to build a portal at your current location
- **Emergency Teleporter** — automatically teleports the player when their health falls below a set threshold (requires a Portable Teleporter in the inventory)
- **Quantum Teleporter** — transfers energy, items, and fluids between linked locations and can also pull items from adjacent chests

## Compatibility

The following APIs are used to interact with other tech mods:

- **Team Reborn Energy API** — energy transfer
- **Fabric Transfer API** — item and fluid transfer

Compatibility has also been tested with Ad Astra fluid pipes and energy, Galacticraft 5 energy and oxygen transfer through the **Quantum Teleporter**, and Tech Reborn energy

## Modpack Use

Phase Teleporters is especially useful in modpacks with many dimensions, planets, and remote bases

It doesn't replace exploration, but makes repeated travel between already explored locations easier

---

Phase Teleporters was originally created for **Galacticraft 5** to make traveling between planets more convenient, for example, building a base on the Moon and quickly traveling between it and Earth using teleporters

The project is inspired by **[Mekanism](https://modrinth.com/mod/mekanism)**
